# Biomarker Origins 2026

Code repository for **Tumor intrinsic and extrinsic origins of circulating genomic and proteomic biomarkers for early detection of lung cancer**.

This repository contains the analysis code, model training scripts, and supporting methods used to produce the results and figures in the accompanying paper.

---

## Repository structure

```
biomarker_origins_2026/
├── data/              # Input data used by the analysis scripts
├── methods_code/      # Pipelines and utilities for feature generation
├── models_code/       # Code for training machine learning models
├── analysis_code/     # Scripts that generate the paper's figures
└── outputs/           # Generated figures and analysis outputs
```

**`data/`** — Input data files consumed by the analysis scripts. Three large
public reference files are not included here (see [Data access](#data-access)
below). The directory also contains `Extended/` (longitudinal, fragment-length
and methylation inputs), `delfi3-LUCAS/` (the wide-format LUCAS fragmentomics
matrix), and `reproduce_lucas_wflow/`, a vendored copy of the LUCAS workflow
repository.

**`methods_code/`** — Code used to generate features and supporting analyses,
together with the reference files the feature pipelines depend on
(`WG/ref/`). Intermediate sequencing output under `WG/results/` is available
from EGA rather than from this repository.

**`analysis_code/`** — Notebooks that produce the figures in the paper.
Organized by figure (`Fig2/` … `Fig6/`), with extended data and supplementary
figures in `FigExtended/`.

**`models_code/`** — Scripts for training and evaluating the machine learning
models. `model_training/` holds the preprocessing and training notebooks;
`FINAL/` holds the fitted models and saved predictions.

**`outputs/`** — Generated figures and analysis outputs, organized by figure
number to mirror `analysis_code/`.

---

## Requirements

- **R** ≥ 4.4.3
- Roughly 55 R packages across CRAN and Bioconductor, including `tidyverse`,
  `caret`, `glmnet`, `recipes`, `ComplexHeatmap`, `GenomicRanges` and
  `rtracklayer`. The complete list is in `install_packages.R`.

To install everything the notebooks need, run

```bash
Rscript install_packages.R
```

from the repository root. Only missing packages are installed, so it is safe to
re-run. Bioconductor packages are handled through `BiocManager`.

> **Note:** several analyses use `library(rlucas)`, which is not on CRAN.
> `install_packages.R` installs it from the
> [`reproduce_lucas_wflow`](https://github.com/cancer-genomics/reproduce_lucas_wflow/tree/master/code/rlucas)
> repository; a copy is also vendored here at
> `data/reproduce_lucas_wflow/code/rlucas`. The `models_code` notebooks rely on
> the `meta` and `bins5mb` datasets that ship with this package.

## Data access

Most input data is included in this repository. Three files are large
redistributions of public resources and must be downloaded separately and
placed in `data/`:

| File | Source | Notes |
|------|--------|-------|
| `rna_single_cell_cluster.tsv` | [Human Protein Atlas](https://www.proteinatlas.org/download/tsv/rna_single_cell_cluster.tsv.zip) | Single-cell RNA expression by cluster |
| `rna_single_cell_type.tsv` | [Human Protein Atlas](https://www.proteinatlas.org/download/tsv/rna_single_cell_type.tsv.zip) | Single-cell RNA expression by cell type |
| `cancer_lung_filtered.tsv` | [Derived from HPA/TCGA cancer data](https://www.proteinatlas.org/download/tsv/rna_cancer_sample.tsv.gz) | RNA expression filtered to LUAD and LUSC |

All three are public and can be downloaded directly from the links above.

`data/delfi3-LUCAS/lucas-features-wide.5mb.hg19.csv` is included here. It is a
wide-format matrix derived once from the long-format DELFI 3.0 pipeline output
(`allfeatures.5mb.hg19.csv`): z-scores pivoted wide on chromosome arm, `cov_*`
and `zscore_NA*` columns dropped, and rows restricted to participants present
in the `rlucas` metadata. The long-format source and the corresponding MICA
feature matrix are available from EGA, as are the aligned sequencing data and
the per-sample intermediates under `methods_code/WG/results/`.

## Reproducing the figures

After downloading the three Human Protein Atlas files into `data/`, run the notebooks in
`analysis_code/`. Each figure folder contains the notebook(s) that produce the
corresponding figures in `outputs/`. Notebooks use paths relative to their own
directory (`../../data/`, `../../outputs/`), so run them from where they live.
